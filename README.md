Soy estudiante de Ingeniería de Sistemas y desarrollador de software junior, enfocado en la construcción de aplicaciones web y de escritorio, el desarrollo backend y la integración de bases de datos.

Me interesa crear soluciones funcionales, mantener un código organizado y comprender cada etapa del desarrollo, desde el diseño de la arquitectura hasta el despliegue de una aplicación.
